# AI Workflow Playbook

A practical collection of frameworks for identifying where AI and automation can remove friction, improve decision quality, increase capacity, and create measurable operating leverage.

This repository is intentionally business-first. The objective is not to automate for the sake of automation. It is to understand the constraint, redesign the workflow, apply the right tool, and measure whether the outcome actually improved.

## Core Approach

**Sense → Diagnose → Design → Build → Drive → Measure**

1. **Sense** — establish what is happening now with observable data.
2. **Diagnose** — separate root causes from symptoms.
3. **Design** — define the improved workflow before selecting technology.
4. **Build** — create the smallest useful solution or MVP.
5. **Drive** — put the solution into the real workflow and support adoption.
6. **Measure** — compare before/after performance and decide whether to scale, revise, or stop.

## Operating Principles

- Start with the business constraint, not the model.
- Automate repeatable judgment before automating irreversible decisions.
- Keep humans accountable for high-impact outcomes.
- Measure cycle time, quality, cost, adoption, and rework.
- Prefer small, testable changes over large speculative transformations.
- Treat AI outputs as inputs to a decision process, not as unquestioned truth.

The examples here are frameworks and prototypes unless a document explicitly identifies a real-world case. They are designed to show how I structure problems, evaluate trade-offs, and turn new technology into practical business workflows.
